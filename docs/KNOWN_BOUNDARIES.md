# 已知边界

- Gateway 是外部身份与接口边界；/interior/** 在 Gateway 返回 404，生产还必须用网络策略禁止公网直连业务服务端口。
- 当前后台授权仍依赖可信管理网络，完整 RBAC、密钥轮换和审计平台不在本轮交易重构内。
- v1～v4.1 仅为历史材料，当前只运行 v5/reference。
- Redis 与 MySQL 不构成跨存储事务。Lua 将预占和事件原子化，但 Redis 主从异步复制切换仍可能丢最近受理写。
- Stream 是有界短期工作队列，不是长期事件日志。长期业务事实位于 MySQL，异常原消息位于 d_order_stream_failure。
- 单个节目所有库存 Key 位于同一 Hash Slot；增加 Redis Cluster 主节点不能线性提高该节目吞吐。
- Lua 运行时错误没有 SQL 式回滚。脚本在任何写操作之前完成参数、Key 类型、销售版本和积压阈值校验。
- 单交易库消除核心交易数据的跨库窗口，但支付渠道、Redis 状态同步和用户服务仍是外部系统边界。
- Program、Pay、User 的历史分片本轮保留；订单主链已退出 ShardingSphere。
- 预热采用维护窗口原地重建，不提供双版本无感切换；已有销售时必须以交易库状态为准。
- 到期扫描和 Redis 同步使用批量任务；大规模部署需要验证任务分片、索引、锁等待和故障恢复时间。
- Elasticsearch 只用于搜索，关闭时不能影响下单正确性。
- 本地 Docker 是单节点演示环境，不能证明 MySQL、Redis、Nacos 或 Elasticsearch 高可用。
- 模拟支付用于闭环；真实支付证书、回调验签、渠道对账和资金合规需要独立实施。
- 当前主链单元测试已覆盖事务顺序、价格拒绝、重复请求和状态 CAS；完整 kill、停库、Redis 切换与容量报告仍需按演练手册执行。
